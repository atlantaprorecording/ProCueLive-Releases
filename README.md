# ProCueLive-Releases
ProCue Live by Atlanta Pro Recording is a live audio cueing and acoustic optimization suite for Windows &amp; Mac. Trigger soundboards with per-pad EQ and playlists, time-align speaker arrays with built-in DVA chirp deconvolution, analyze rooms with a 31-band RTA, and run live 48 kHz vocal DSP—all in one locked-down touring console.
